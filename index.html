> Mundo e som

O mundo é salvo sozinho a cada ~45 s e volta quando você abrir de novo neste aparelho/navegador.
⚠ Dica: o primeiro carregamento é demorado, e gerar o mapa pode levar até 1 ou 2 minutos no celular. Jogue com o aparelho deitado (paisagem).

> Sobre

Esta é uma versão do Minecraft Classic (Survival Test 0.30) que roda no navegador, usando CheerpJ para executar o Java e uma camada de LWJGL feita em JavaScript e WebGL.

O mapa é gerado toda vez que você entra, então o progresso não é salvo. Ainda não há som.
