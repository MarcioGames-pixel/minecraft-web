> World and sound

The world is automatically saved about every 45 seconds and restored when you reopen it on this device/browser.
⚠ Tip: The first load takes a while, and generating the world may take 1–2 minutes on a phone. Play with your device in landscape mode.

> About

This is a browser version of Minecraft Classic (Survival Test 0.30), using CheerpJ to run Java and a JavaScript/WebGL LWJGL layer.

The map is generated each time you enter, so progress is not saved. Sound is not fully supported yet.
